      DAA Viva Voce & Oral Defense Guide Examiner Q&A Reference

      Prepared specifically for CSEG3053: Design and Analysis of Algorithms viva defense. Use these concise answers to address questions on algorithm selection, recurrence relations, complexity proofs, and design paradigms.

      1. Why Dijkstra vs Bellman-Ford?

      Dijkstra: Uses a greedy approach, repeatedly selecting the unvisited node with the smallest tentative distance. It operates in O(V² + E) (or O((V+E) log V) with min-heap). It requires all edge weights to be non-negative.

      Bellman-Ford: Uses Dynamic Programming / repeated relaxation of all |E| edges |V| - 1 times. It runs in O(V · E) and correctly handles negative edge weights (such as downhill regenerative braking in EVs) while detecting negative-weight cycles.

      2. Negative-Cycle Detection Proof

      In a graph with no negative cycles, any shortest simple path contains at most |V| - 1 edges. Thus, |V| - 1 iterations of edge relaxation suffice.

      if (dist[u] + weight < dist[v]) { // Negative cycle detected! return -1; }

      If any distance decreases on the |V|-th pass, a negative cycle must exist along a reachable path.

      3. Greedy Choice in Station Placement

      Station placement is modeled on the Set Cover / Maximum Coverage Problem, which is NP-hard. We implement two polynomial-time greedy approximations:

      • Strategy A (Connectivity): Locally picks vertex with max remaining degree d(v).
      • Strategy B (Demand): Locally picks vertex with max simulated demand score.

      Greedy heuristics provide a known (1 - 1/e) ≈ 63.2% approximation ratio for submodular coverage objectives.

      4. Quick Sort & Recurrence Relations

      Recurrence (Best/Average Case):
      T(N) = 2T(N/2) + O(N) → By Master Theorem (Case 2), T(N) = O(N log N).

      Worst Case:
      When partitions are maximally unbalanced (0 and N-1 elements), T(N) = T(N - 1) + O(N) = O(N²).

      Binary Search:
      T(N) = T(N/2) + O(1) → T(N) = O(log N).

      5. Adjacency List Graph Data Structure

      The network is stored as an array of Node structures, each containing an adjacency array of Edge records:

      typedef struct { int destination; double distance; double time; } Edge; typedef struct { char name[MAX_NAME]; int edge_count; Edge edges[MAX_NODES]; int has_station; } Node;

      Space efficiency: O(V + E) instead of O(V²) matrix storage.

      6. Integration with GUI Architecture

      The GUI is not a mockup! The native C executable (ev_server.exe) uses Winsock2 to expose a local REST API that invokes the actual C algorithms (dijkstra(), fastest_route(), bellman_ford(), run_greedy_strategy(), quick_sort()) in memory on the actual graph data structure.
